# 3D 知识花园

Quartz 独立可视化花园，默认地址 `/garden`。使用仓库内的 Three.js 构建真实立体地形、低多边形植物、光照与投影，不依赖外部模型、贴图或字体服务。

## 探索

- 拖动旋转，滚轮缩放，右键拖动平移；手机单指旋转、双指缩放和平移。
- 点击植物或标题打开详情并平滑靠近；直接关联的笔记显示连线、金色标记和可点击的详情入口，其他植物适度变浅。
- 搜索标题、标签、摘要后，选择结果定位到植物；支持主题和成长阶段组合筛选。
- 筛选只淡化不匹配的植物，不改变场景坐标。
- 默认不自动旋转；「漫游」开启自动环绕，「全景」恢复总览。
- 场景获得焦点时：方向键旋转，`+` / `-` 缩放，`Home` 返回全景。`/` 聚焦搜索，`Escape` 关闭详情。
- 可切换笔记列表。WebGL 不可用或渲染上下文丢失时自动降级为列表。
- 场景不在视口、页面进入后台或显示列表时暂停渲染；动画上限约 30 帧，遵循减少动态效果偏好。超过 80 篇时关闭枝叶摆动，静止场景按需渲染。

## 笔记与布局

三档 `maturity`：`seed`（默认种子）、`growing`（生长中）、`tree`（常青）。常青笔记可以另写 `fruit: true`，表示想法已在实践中产生价值。不会按字数、修改日期推断成熟度。旧值 `sprout`、`sapling`、`fruit` 会分别映射到 `growing`、`growing`、`tree + fruit`。

24 篇以内共用一座主岛；更多内容按第一个标签的顶层名称分岛，无标签时归为「未分类」。坐标基于 slug 与主题确定，修改日期、成熟度或输入排序不会重新洗牌。新增笔记时尽量沿用原位置；遇到碰撞或跨越群岛阈值时会调整布局。

草稿、未列出页面、首页及标签索引不进入花园。`limit` 控制最多展示数量，超过上限时显示实际展示数与总数。关联线只连接当前花园中的真实笔记，不生成虚构关系。

## 开发

- `src/page.html`、`src/garden.css`：页面结构与响应式界面。
- `src/garden.js`：检索、筛选、详情、降级流程。
- `src/scene.js`：三维地形、模型、光照、镜头、拾取及资源清理。
- `src/layout.js`：可测试的确定性布局。
- `dist/index.js`：Quartz emitter，提取内容、链接、日期并生成页面。

在仓库根目录执行：

```sh
npm run build --prefix plugins/garden
node --test plugins/garden/src/layout.test.js
npx quartz build
```

`dist/garden-island.js` 需随脚本源码更新并提交。HTML 与 CSS 由 emitter 直接读取。插件选项 `slug` 控制页面地址。
